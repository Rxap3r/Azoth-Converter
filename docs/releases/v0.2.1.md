A small update that makes problems easier to report and updates cleaner.

## What's new

- **Error log:** if something goes wrong, the details are saved in a file on your computer (Settings → **Error log…**) and you see a short message instead of the app just closing. The log is never sent anywhere; it may contain file names, so have a look before attaching it to a problem report.
- **Uninstall…** at the bottom of Settings: removes the app and its settings with the normal Windows uninstaller. Your own and converted files are not touched.
- **Cleaner updates:** installing a new version over an old one removes the old program files first. Your settings are kept.
- **Open output folder** only appears when all converted files are in one folder; otherwise use **Show in folder** on each file. "Finished" and the progress bar now clear when you change the file list.

## Downloads

| File | What it is |
|---|---|
| **AzothConverter-Setup-0.2.1.exe** | **Installer (recommended).** Installs the app with a Start menu entry and a clean uninstall under *Settings → Apps*. No admin rights needed. Installing it over 0.2.0 or 0.1.0 updates the app and keeps your settings. |
| **AzothConverter-portable-0.2.1.zip** | **Portable version, no installation.** Unzip the folder anywhere and run `AzothConverter.exe`; to remove it, delete the folder. Same app as the installer. Note: it still keeps its few settings in `%APPDATA%\Azoth Converter`, which stays behind when you delete the folder (a fully portable version is planned). |
| Source code (zip / tar.gz) | Added by GitHub to every release: the project's code at this version. Only needed by developers. |

Windows may show "Windows protected your PC" if the files aren't signed: click **More info → Run anyway**.
[Code signing policy](https://github.com/Rxap3r/Azoth-Converter/blob/main/CODE_SIGNING.md)
For Word, Excel and PowerPoint formats, install the free [LibreOffice](https://www.libreoffice.org/download/) (not needed for PDFs and images, or for Word → PDF when Microsoft Word is installed).

## Known limitations

- The files are not code-signed yet, so Windows shows a warning on first start.
- Compressing PDFs, PDF passwords and text recognition (OCR) are not in this version yet; they are planned next.
