Text recognition (OCR) for scans and photos, more PDF tools, and a clearer finish: everything still works fully offline.

## What's new

- **Text recognition (OCR)** in English, German, French and Italian, done on your computer:
  - scanned PDFs and photos of documents become **Word** or **text** files;
  - photos become a **searchable PDF**: tick *Make the text searchable* on the Convert page;
  - **PDF tools → Make searchable** adds the text to a scanned PDF, so you can search, select and copy it. The pages look exactly the same, with a progress bar and a Cancel button;
  - sideways or upside-down pages are read and turned the right way up (can be turned off in Settings).
- **Compress PDF** (PDF tools → Compress): a smaller copy in three levels, from "no quality loss" to "smallest file". Text stays sharp; if the file can't get smaller, nothing is saved.
- **Password** (PDF tools → Password): lock a copy of a PDF with a password (AES-256), or save an unlocked copy of your own PDF. The password is never stored.
- **Choose the file name** in every PDF tool, next to *Save to*.
- **"Done" card** when a conversion finishes, with **Open file** and **Open folder**, and a Windows notification when the app is in the background (can be turned off in Settings).
- PDF tools warn when a PDF is digitally signed, because a copy can't keep the signature valid.
- Edit pages: the move buttons are now **◀ Move** and **Move ▶**.
- Fixed: the Settings page no longer cuts off buttons when the window is low or Windows uses larger text.

## Known limitations

- Text recognition takes a few seconds per page. Check names and numbers in the result: unclear print or handwriting can be misread.
- Scans → Word gives the text as plain paragraphs, without the original layout or pictures.
- The download is about 40 MB bigger than 0.2.1 because of the text recognition languages.
