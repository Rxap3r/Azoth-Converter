First release of **Azoth Converter**: a file converter for Windows that works completely offline. Your files never leave your computer.

## What it converts

- **Word → PDF** (DOCX, DOC, ODT, RTF, TXT). Uses Microsoft Word if it's installed for an exact layout, otherwise LibreOffice.
- **PDF → Word**: editable DOCX with tables and images. Also PDF → images (one per page) and PDF → text.
- **Excel and PowerPoint** → PDF and between their formats; CSV ↔ Excel.
- **Images**: JPG, PNG, WebP, HEIC (iPhone), AVIF, TIFF, GIF, BMP, ICO, and any image → PDF.
- PDF merge and split (command line).

The full list is in [docs/FORMATS.md](https://github.com/Rxap3r/Azoth-Converter/blob/main/docs/FORMATS.md) and in the app under **Supported formats**.

## Highlights

- **Private:** no uploads, no account, no tracking, no automatic internet connection.
- **1:1 quality:** photos go into PDFs unchanged, lossless images stay lossless; quality setting with sensible minimums.
- **Safe:** documents are opened with macros off; originals are never changed or overwritten; photo GPS data is removed by default.
- **Clean uninstall:** removes everything, including settings and temporary files.

## Downloads

| File | What it is |
|---|---|
| **AzothConverter-Setup-0.1.0.exe** | **Installer (recommended).** Installs the app with a Start menu entry and a clean uninstall under *Settings → Apps*. No admin rights needed. |
| **AzothConverter-portable-0.1.0.zip** | **Portable version, no installation.** Unzip the folder anywhere and run `AzothConverter.exe`; to remove it, delete the folder. Same app as the installer. Note: it still keeps its few settings in `%APPDATA%\Azoth Converter`, which stays behind when you delete the folder (a fully portable version is planned). |
| Source code (zip / tar.gz) | Added by GitHub to every release: the project's code at this version. Only needed by developers. |

Windows may show "Windows protected your PC" because the files aren't signed yet: click **More info → Run anyway**.
For Word, Excel and PowerPoint formats, install the free [LibreOffice](https://www.libreoffice.org/download/) (not needed for PDFs and images, or for Word → PDF when Microsoft Word is installed).

## Known limitations

- Scanned PDFs (pictures of pages) can't be converted to Word yet; text recognition (OCR) is planned.
- English only for now.
- Not yet code-signed.
