Icons (ICO) now come out at the correct size.

## What's new

- **Icons have all sizes up to 256 × 256 px.** Before, a picture that is not square (most photos and logos) gave only small, squashed icons, and many viewers showed only 16 × 16 px. Now the picture goes in the centre of a transparent square (nothing is cut off), and the largest size comes first.
- **Larger icons from small pictures:** a note now tells you when an icon is smaller than 256 × 256 px. Select a larger size under **More options → Picture size** to make it larger.
- **Fixed:** pictures smaller than 16 px no longer give an empty icon file.

## Downloads

| File | What it is |

| **AzothConverter-Setup-0.7.1.exe** | **Installer (recommended).** Installs the app with a Start menu entry, the Explorer right-click menu ("Convert with Azoth Converter") and a clean uninstall under *Settings → Apps*. No admin rights needed. |

The files aren't signed yet, so Windows may show "Windows protected your PC": click **More info → Run anyway**.
Code signing is planned: [code signing policy](https://github.com/Rxap3r/Azoth-Converter/blob/main/CODE_SIGNING.md)
For Word, Excel and PowerPoint formats, install the free [LibreOffice](https://www.libreoffice.org/download/) (not needed for PDFs and images, or for Word → PDF when Microsoft Word is installed).

## Known limitations

- Small pictures do not become larger icons automatically, because enlarging makes them blurry. Use **Picture size** to enlarge them.
- The right-click menu appears under **Show more options** on Windows 11; the short Windows 11 menu needs a signed app, which comes with code signing.
- Text recognition takes a few seconds per page. Check names and numbers in the result: unclear print or handwriting can be misread.
