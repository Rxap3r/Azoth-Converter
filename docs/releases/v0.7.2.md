Icons (ICO) now show at their large size in the Windows Photos app.

## What's new

- **Icons show large in the Photos app.** Before, the Photos app showed icons from Azoth Converter at 16 × 16 px, although they contain all sizes up to 256 × 256 px. Azoth Converter now writes icons like Windows does: the largest size first, classic bitmaps for the small sizes and PNG only for 256 × 256 px.

## Downloads

| File | What it is |
|---|---|
| **AzothConverter-Setup-0.7.2.exe** | **Installer (recommended).** Installs the app with a Start menu entry, the Explorer right-click menu ("Convert with Azoth Converter") and a clean uninstall under *Settings → Apps*. No admin rights needed. |
| **AzothConverter-portable-0.7.2.zip** | **Portable version, no installation.** Unzip the folder anywhere (also a USB stick) and run `AzothConverter.exe`; to remove it, delete the folder. Same app as the installer, but it keeps its settings and temporary files in a `data` folder next to itself, so nothing is left on the computer. It has no Explorer right-click menu (that would have to be registered in Windows); drag files onto the window instead. |
| Source code (zip / tar.gz) | Added by GitHub to every release: the project's code at this version. Only needed by developers. |

The files aren't signed yet, so Windows may show "Windows protected your PC": click **More info → Run anyway**.
Code signing is planned: [code signing policy](https://github.com/Rxap3r/Azoth-Converter/blob/main/CODE_SIGNING.md)
For Word, Excel and PowerPoint formats, install the free [LibreOffice](https://www.libreoffice.org/download/) (not needed for PDFs and images, or for Word → PDF when Microsoft Word is installed).

## Known limitations

- Small pictures do not become larger icons automatically, because enlarging makes them blurry. Use **Picture size** to enlarge them.
- The right-click menu appears under **Show more options** on Windows 11; the short Windows 11 menu needs a signed app, which comes with code signing.
- Text recognition takes a few seconds per page. Check names and numbers in the result: unclear print or handwriting can be misread.
