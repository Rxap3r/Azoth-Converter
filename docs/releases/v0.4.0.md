Change the size of your pictures, a fully portable version for USB sticks, and a crash fix.

## What's new

- **Change picture size.** Make photos smaller or bigger while converting, or keep the format and only change the size with the new **Change size only** tile (saved as "name (resized)", the original stays untouched). Pick a ready-made size from 8K and 4K to Full HD (selected first) and smaller, or choose a width, a height, a percentage or your own custom size. Proportions are always kept, and portrait photos are turned automatically: with Full HD, a portrait photo becomes 1080 × 1440 instead of tiny. Tick **Don't enlarge smaller pictures** to only shrink the big ones (for e-mail, for example). Each file shows its new size when it's done. Nothing is resized unless you choose a size.
- **Fully portable version.** The portable ZIP now keeps its settings, error log and temporary files in a `data` folder next to the program, so nothing is left on the computer. Run it from a USB stick and delete the folder to remove it.
- **"Show metadata" button** (ⓘ) on every photo in the list: see what's hidden in a photo (location, camera, date …) with one click.
- **Clearer program names.** The command-line program is now called `azoth-terminal.exe` (was `azoth.exe`). Double-clicking it shows a short note on how to use it; to use the app, open `AzothConverter.exe` (or the Start menu entry) as before.
- **Fixed:** the app could crash ("access violation") while converting several photos at once. This was probably also the rare crash some saw in 0.2.0.

## Known limitations

- Enlarging a picture makes it bigger but not sharper: it adds no detail. JPG, WebP, HEIC and AVIF pictures are saved again when resized, with the quality you chose.
- The portable version: settings from an installed version aren't carried over, and Office formats still need LibreOffice (or Word) installed on the computer. Windows itself may remember that the app ran (as it does for every program).
- Text recognition takes a few seconds per page. Check names and numbers in the result: unclear print or handwriting can be misread.
