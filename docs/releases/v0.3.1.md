Faster when you convert many files at once, and Word → PDF now really uses Microsoft Word.

## What's new

- **Word → PDF with Microsoft Word works.** When Word is installed, it now really does the conversion, for the most exact layout. Before, Word always failed quietly and LibreOffice took over.
- **Much faster batches.** Word and LibreOffice now convert up to 10 files per start instead of starting again for every file (about 4 times faster for 10 Word files). Up to 4 photos are converted at the same time (about 4 times faster for many large photos). The results are exactly the same as before.
- **PDF restrictions are kept.** Merge, Split and Edit pages now keep a PDF's "no printing" or "no copying" settings in the new file, like Compress already did.
- **"Download LibreOffice…" button** when LibreOffice isn't installed. It opens the official download page in your browser; the app itself still never goes online.
- **Clear note when Word fails:** the file then says "Word failed, LibreOffice was used", with Word's reason in the tooltip and in the error log.
- **Fixed:** in Settings, the text below "Check for updates", "About" and "Error log" no longer covers those buttons with larger Windows text.

## Known limitations

- A merged PDF made from files with "no printing" or "no copying" keeps those restrictions, and they can't be removed from the merged file. Remove them from the original files first (PDF tools → Password) if you have the owner password.
- Converting several PDF pages to images still happens one page after another.
- Text recognition takes a few seconds per page. Check names and numbers in the result: unclear print or handwriting can be misread.
