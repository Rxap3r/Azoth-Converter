A bigger update: a new, cleaner look with light and dark mode, PDF tools in the app, and a way to remove hidden details (like the GPS location) from photos.

## What's new

- **New look:** a sidebar with **Convert**, **PDF tools**, **Supported formats** and **Settings**. Choose *Light*, *Dark* or *Follow Windows* under Settings → Appearance.
- **PDF tools:** **merge** PDFs in any order, **split** a PDF into single pages or ranges like "1-3, 5", and **edit pages** (turn, delete, reorder) with page previews. Pages are copied exactly; nothing is re-compressed.
- **Remove photo metadata:** choose **Remove metadata only** to strip the GPS location, camera, date, author and other hidden data from JPG, PNG, WebP, GIF, TIFF, HEIC and AVIF photos without changing the picture. Right-click a file → **Show metadata…** to see what a photo contains first.
- **Choose the file name** of the result when converting a single file.
- Every file in the list has its own **remove** button, progress bar, and **Open** / **Show in folder** once it's done.
- The quality choices (Maximum / High / Smaller) are explained in plain words.
- **Check for updates…** in Settings opens this download page in your browser. The app itself still never goes online.
- Command line: `azoth clean`, `azoth pdf split --ranges`, `azoth pdf edit`.

For Word, Excel and PowerPoint formats, install the free [LibreOffice](https://www.libreoffice.org/download/) (not needed for PDFs and images, or for Word → PDF when Microsoft Word is installed).

## Known limitations

- The files are not code-signed yet (applied for), so Windows shows a warning on first start.
- Compressing PDFs, PDF passwords and text recognition (OCR) are not in this version yet; they are planned next.
- Removing metadata works for photos; PDF and Office files (author, company, edit history) come later.
