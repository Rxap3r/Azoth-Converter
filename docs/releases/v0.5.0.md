Microsoft Excel and PowerPoint as converters, passwords and metadata removal for Office files, a right-click menu in Explorer, and "Enhance with AI" for photos.

## What's new

- **Right-click menu in Explorer.** Right-click a file → **Convert with Azoth Converter** → e.g. **To PDF**, **Remove metadata** or **Open in Azoth Converter…**. The app opens and converts right away with your usual settings; several selected files are converted together. On Windows 11 it's under **Show more options**. Installer only (see Downloads).
- **Microsoft Excel and PowerPoint convert their own files.** Where Microsoft Office is installed, Excel and PowerPoint now make PDFs with the exact layout (like Word already did), and Word, Excel and PowerPoint also convert between their formats (e.g. DOC → DOCX, XLS → XLSX, PPT → PPTX). On a PC with Microsoft Office, LibreOffice is no longer needed. The "LibreOffice is missing" message now only names what nothing on the PC can do.
- **Passwords for Word, Excel and PowerPoint files.** The **Password** tool, now with its own page in the sidebar, locks DOCX, XLSX and PPTX files with a password (AES-256, opens normally in Office) or removes the password from your own file (also DOC, XLS, PPT). Password-protected Office files can also be converted: the app asks for the password and never saves it.
- **Remove metadata from documents.** **Remove metadata only** and **Show metadata…** now also work for PDF, Word, Excel and PowerPoint files (DOCX, XLSX, PPTX): author, company, dates, editing time, the template's folder, Word's edit history and earlier versions hidden inside a PDF are removed. Names on comments and tracked changes become "Author"; the text, comments and changes themselves stay exactly the same, and the app checks this before saving.
- **Enhance with AI.** Under **Picture size**, "Enhance with AI" makes enlarged photos sharp instead of blurry, or makes photos at their original size sharper with less noise. Runs completely on your computer. Never on by default.
- **PDF → Word shows progress** page by page for large PDFs, and **Cancel** works between pages.

## Known limitations

- "Enhance with AI" invents detail that wasn't in the photo: don't use it for documents, evidence or ID photos. It takes a while on large photos.
- The right-click menu appears under **Show more options** on Windows 11; the short Windows 11 menu needs a signed app, which comes with code signing.
- Metadata can be removed from DOCX, XLSX and PPTX, not from old DOC, XLS and PPT files (convert them first). Digitally signed and password-protected PDFs are left unchanged.
- Text recognition takes a few seconds per page. Check names and numbers in the result: unclear print or handwriting can be misread.
